# ShrinkFlow v1.2.0 — 一页纸摘要

## 项目名
**ShrinkFlow** — 元数据感知的视频批量压缩工具

## 一句话定位
用可解释规则引擎分析每个视频的编码特征，为每个文件独立推荐最优压缩策略，让普通用户无需理解 CRF、码率、编码格式，也能完成批量压缩决策。

## 核心痛点
1. **一刀切** —— 所有视频用同一参数，不管编码特征差异
2. **不安全** —— 压完直接覆盖原文件，输出变大无法恢复
3. **门槛高** —— FFmpeg 参数复杂，普通用户不会用

## 核心方案
6 层规则引擎（硬排除 → 编码分类 → 证据收集 → 目标决策 → 高风险降级 → 低收益过滤），基于 BPPF（每帧每像素比特数）和编码效率分级，为每个视频生成 compress / skip / confirm 建议，附带 17 种可解释的 reason code。

## 3 个最大亮点

1. **Per-Video 策略** —— 每个视频独立分析、独立推荐，一个批次里不同视频可能用不同压缩模式
2. **三级策略目标** —— 安全优化 / 智能推荐 / 空间优先，一个滑块控制全局风险偏好
3. **四重安全保护** —— 输出变大保护、原子替换、高风险确认、低收益过滤

Electron 33 · React 18 · Zustand · TypeScript · Tailwind CSS · FFmpeg（内嵌）· electron-vite · Vitest
