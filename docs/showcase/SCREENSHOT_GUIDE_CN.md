# ShrinkFlow v1.2.0 — 截图拍摄清单

## 通用设置

- **窗口尺寸：** 1280 × 800（标准 16:10）
- **主题：** Catppuccin Mocha 暗色主题（默认）
- **语言：** 中文（根据目标受众选择，面试作品集建议中文）
- **FFmpeg 状态：** 确保设置页显示"已就绪"
- **截图工具：** Windows Snipping Tool 或 ShareX，PNG 格式

## 截图 1：首页 / 导入视频

### 目的
展示应用入口、界面风格和导入方式。

### 要展示的 UI 元素
- 空状态页面（未导入视频）
- "选择文件"和"选择文件夹"按钮
- 拖拽区域提示文字
- 左侧导航栏（压缩 / 历史 / 设置）
- 顶部状态栏（如有 FFmpeg 状态指示）

### 操作步骤
1. 启动 ShrinkFlow
2. 不导入任何视频，停留在首页
3. 确认 FFmpeg 状态为"已就绪"

### 注意事项
- 不要有错误提示或警告
- 如果有 FFmpeg 未就绪的提示，先去设置页修复

## 截图 2：Smart Shrink Plan 面板

### 目的
展示智能计划的核心 UI 和三个策略目标。

### 要展示的 UI 元素
- Smart Shrink Plan 面板
- 三个目标 pill：安全优化 / 智能推荐 / 空间优先
- 预估节省范围（绿色数字）
- 压缩 / 跳过 / 确认计数
- "应用计划"按钮
- 展开的详情面板（原始大小、预估输出、高风险数量）

### 操作步骤
1. 导入一批视频（建议 8-15 个）
2. 等待分析完成
3. 选择"智能推荐"目标
4. 展开详情面板（点击"显示详情"）
5. 截图

### 注意事项
- 确保有数据展示（非空状态）
- 预估节省范围应有具体数值
- 如果所有视频都被跳过，说明素材不合适——换一批包含高码率视频的素材

## 截图 6：压缩进度

### 目的
展示压缩进行中的实时反馈。

### 要展示的 UI 元素
- 整体进度条（约 40-60%）
- 百分比数字
- 已完成 / 总数
- 已用时间
- ETA
- 当前文件名
- 每个视频的独立状态（已完成 / 进行中 / 等待）

### 操作步骤
1. 导入视频，应用 Smart Plan
2. 点击"压缩已选 N 个"
3. 等待进度到 40-60%
4. 截图

### 注意事项
- 不要截 0% 或 100%——中间进度更有信息量
- ETA 应有值（不是"--"）
- 如果有双 Pass 编码的视频，能看到阶段标记更好

## 截图 8：输出变大保护

### 目的
展示安全保护机制。

### 要展示的 UI 元素
- 某视频标记为"输出大于原始"
- 原始文件未被替换的提示
- 或：历史记录中 noSaving 标记

### 操作步骤
1. 找一个 bppf ≤ 0.045 的已压缩视频（如一个低码率 HEVC 视频）
2. 用"空间优先"策略压缩它
3. 如果压缩后变大，截图

### 注意事项
- 这个效果依赖特定素材，不是每次都能触发
- 如果没有触发，可以在截图清单中标注"需要特定素材触发"
- 触发条件：HEVC→H.264 重压缩，且输出 ≥ 输入

1. 10 张截图是否都有
