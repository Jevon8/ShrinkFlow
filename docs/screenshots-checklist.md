## 截图工具推荐

### Windows

- **Snipping Tool** — Windows 自带，简单易用
- **ShareX** — 免费开源，功能强大，支持标注
- **Snipaste** — 免费，支持贴图到屏幕

### macOS

- **Screenshot** — macOS 自带（Cmd+Shift+4）
- **CleanShot X** — 付费，功能最全

## 截图规范

### 尺寸建议

- **README 配图** — 宽度 800-1200px，确保在 GitHub 上清晰显示
- **作品集展示** — 宽度 1200-1920px，确保在大屏幕上清晰
- **面试演示** — 宽度 1280-1920px，确保投影仪上清晰

### 命名规范

- 使用数字前缀排序（01、02、03...）
- 使用小写字母和连字符（kebab-case）
- 包含简要描述（如 `01-empty-state.png`）

### 文件格式

- **PNG** — 推荐，无损压缩，适合 UI 截图
- **JPG** — 可选，有损压缩，文件更小

### 后期处理

- 可以添加简单的标注（箭头、高亮框）
- 保持截图干净，不要有太多标注
- 确保文字清晰可读
- 如果需要，可以裁剪掉不相关的部分
